Start the Mtech server to open Admin

This file was opened directly from your computer. Admin needs the Mtech server for sign-in, data, and API access.

  1. Open PowerShell in the Mtech project folder.
  2. Run npm start.
  3. Open http://localhost:8000/admin.

Once the server is running, this page opens Admin by itself.
